Dragon Hatchling (BDH) Architectural Mechanics

The Baby Dragon Hatchling (BDH) architecture demonstrates how sparse non-negative neural activations convert linear recurrence into an associative memory store immune to catastrophic interference[cite: 1].

01 Mathematical Formulation

Every memory write executes a rank-1 outer product update without gradient backpropagation[cite: 1]:

Synaptic Plasticity: Mₜ = λ · Mₜ₋₁ + yₜ xₜᵀ
Associative Retrieval: ŷ = M · x_query
Sparse Projections: x = TopK-ReLU(W_K · e), y = TopK-ReLU(W_V · e)
02 Interference Immunity via Orthogonality

When querying associative memory for concept x_a, the retrieved vector expands to:

ŷ_a = y_a (x_aᵀ x_a) + ∑_{i ≠ a} y_i (x_iᵀ x_a)

In standard dense vectors, the crosstalk summation ∑ y_i (x_iᵀ x_a) = O(p) quickly drowns out the target signal. With non-negative Top-k ReLU (k ≈ 3–4, ~5%), the collision probability between any two random vectors drops below 14%, ensuring x_iᵀ x_a = 0 almost surely![cite: 1]
